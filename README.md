## مقدمه

**ZS-HPD** یک روش پیشرفته برای **حذف نویز از تصاویر** است که نیازی به هیچ داده آموزشی خارجی ندارد. این روش تنها با استفاده از **یک تصویر نویزی** و اطلاعات درونی خود تصویر، عمل دنوایزینگ را انجام می‌دهد.

## چرا Zero-Shot؟

در بسیاری از کاربردهای واقعی، دسترسی به تصاویر تمیز (Ground Truth) غیرممکن یا بسیار دشوار است:

| حوزه کاربرد | چالش |
|-------------|------|
| **تصویربرداری پزشکی** | اشعه X یا MRI تمیز وجود ندارد |
| **عکاسی نجومی** | تصویر بدون نویز ستاره‌ها غیرقابل دستیابی است |
| **دوربین‌های موبایل** | نویز واقعی پیچیده و متغیر است |
| **میکروسکوپ فلورسانس** | نمونه‌ها حساس به نور هستند |

روش‌های Zero-Shot برای **هر تصویر به صورت مستقل** آموزش می‌بینند و به داده خارجی نیاز ندارند.

## ایده اصلی

### دو ویژگی بنیادین تصاویر طبیعی

#### ۱. Spatial Locality (همبستگی مکانی)
> پیکسل‌های مجاور در تصویر، از نظر شدت رنگی همبستگی بالایی دارند، در حالی که پیکسل‌های دور از هم وابستگی آماری کمی دارند.

#### ۲. Non-Local Self-Similarity (شباهت غیرمحلی)
> پچ‌ها و الگوهای بصری مشابه، در مکان‌های مختلف تصویر تکرار می‌شوند (حتی در مقیاس‌های مختلف).

### نوآوری‌های کلیدی

| نوآوری | توضیحات |
|--------|---------|
| **سمپلر محلی (Sd)** | تولید نمونه‌های Down-Sampled با استفاده از گرادیان‌های Sobel در پنجره‌های محلی |
| **سمپلر سراسری (Sr)** | جستجوی کاندیداهای مشابه در **کل تصویر** با وزن‌دهی گوسی |
| **Spectral Weighted Loss** | تمرکز بیشتر روی باندهای فرکانس بالا برای حفظ جزئیات ظریف |

## اجزای پروژه

### ۱. شبکه دنوایزینگ (`network.py`)

```python
شبکه Fully Convolutional با مشخصات:
├── تعداد لایه‌ها: ۸
├── کرنل: ۳×۳ (همه لایه‌ها)
├── کانال‌ها: ۴۸ کانال (لایه‌های میانی)
├── کانال خروجی: ۳ (RGB)
└── تابع فعال‌سازی: ReLU (به جز لایه آخر)
```

### ۲. سمپلر محلی - Sd (`samplers.py`)

**هدف**: تولید نمونه‌های آموزشی Down-Sampled با حفظ کیفیت

**مراحل کار**:
1. **محاسبه گرادیان Sobel** در هر پیکسل
2. **تجمیع گرادیان‌ها** در پنجره ۵×۵
3. **مرتب‌سازی** پیکسل‌ها در کاشی ۲×۲ بر اساس بزرگی گرادیان
4. **گروه‌بندی**: پیکسل‌های ضعیف با هم، پیکسل‌های قوی با هم
5. **تولید نمونه**: چهار خروجی `xl, yl, xh, yh`

**چرا این کار مفید است؟**
- پچ‌های با گرادیان بالا (لبه‌ها، بافت‌ها) و پچ‌های با گرادیان پایین (نواحی صاف) از توزیع‌های آماری متفاوتی پیروی می‌کنند.
- جفت‌کردن هم‌رده‌ها با فرض Noise2Noise سازگارتر است.

### ۳. سمپلر سراسری - Sr (`samplers.py`)

**هدف**: شناسایی وابستگی‌های بلندبرد (Non-Local)

**تفاوت با Pixel2Pixel**:

| ویژگی | Pixel2Pixel | ZS-HPD (Sr) |
|-------|-------------|-------------|
| محدوده جستجو | پنجره ۴۰×۴۰ محلی | **کل تصویر** |
| نمونه‌برداری | جستجوی کامل | **گوسی وزن‌دار** |
| اولویت | فقط شباهت | **شباهت + نزدیکی مکانی** |
| حافظه | ۳۹۰۲ MB | **۷۸۰ MB** |

**فرمول وزن‌دهی گوسی**:
```
p(pi) = (1 / 2πσG²) × exp(-||pi - p0||² / 2σG²)
```

**مراحل**:
1. تبدیل تصویر به فضای YCbCr
2. استخراج پچ ۷×۷ از کانال Y
3. نمونه‌برداری M=1024 کاندیدا با وزن گوسی
4. انتخاب Top-K=10 کاندیدا با کمترین فاصله L1
5. ساخت Pixel Bank با شکل `(H, W, K, C)`

### ۴. Spectral Weighted Loss (`loss.py`)

**مشاهده کلیدی**: نویز به صورت یکنواخت در طیف فرکانسی پخش می‌شود، اما انرژی سیگنال تمیز بیشتر در فرکانس‌های پایین متمرکز است.

**استراتژی**:
- **LF (فرکانس پایین)**: سیگنال غالب → وزن کمتر (α=0.5)
- **HF (فرکانس بالا)**: نویز غالب → وزن بیشتر (β=1.0)

**فرمول**:
```
L_SWL = α · L_LF + β · L_HF
```

**پیاده‌سازی**:
1. تبدیل FFT دو بعدی
2. تقسیم طیف با ماسک دایره‌ای (شعاع نسبی ۰.۲)
3. اعمال Hadamard product
4. تبدیل معکوس و محاسبه MSE

## نحوه استفاده

### ۱. آموزش با نویز گاوسی

```bash
python train.py \
    --input path/to/image.png \
    --noise_type gaussian \
    --sigma 25 \
    --output ./results/gaussian_25 \
    --iterations 1500 \
    --lr 1e-3 \
    --crop_size 256
```

**توضیح پارامترها**:
- `--input`: مسیر تصویر ورودی
- `--noise_type`: نوع نویز (`gaussian` یا `poisson`)
- `--sigma`: شدت نویز گاوسی (مثلاً ۱۰، ۲۵، ۵۰)
- `--output`: پوشه خروجی
- `--iterations`: تعداد ایتریشن (۱۵۰۰ پیشنهاد می‌شود)
- `--lr`: نرخ یادگیری اولیه
- `--crop_size`: برش مرکزی تصویر برای ارزیابی استاندارد

### ۲. آموزش با نویز پواسون

```bash
python train.py \
    --input path/to/image.png \
    --noise_type poisson \
    --lam 50 \
    --output ./results/poisson_50 \
    --iterations 1500 \
    --lr 1e-3 \
    --crop_size 256
```

**توجه**: برای نویز پواسون، `--lam` شدت نویز را تعیین می‌کند (مثلاً ۱۰، ۲۵، ۵۰).

### ۳. آموزش با تصویر Ground Truth (برای ارزیابی)

```bash
python train.py \
    --input path/to/noisy.png \
    --input_gt path/to/clean.png \
    --noise_type gaussian \
    --sigma 25 \
    --output ./results/eval \
    --crop_size 256
```

**خروجی‌ها**:
- `noisy.png`: تصویر نویزی
- `denoised.png`: تصویر دنوایز شده
- `clean.png`: تصویر تمیز (اگر GT ارائه شده باشد)
- `model.pth`: وزن‌های مدل ذخیره‌شده
- `metrics.txt`: مقادیر PSNR و SSIM

### ۴. استنتاج با مدل ذخیره‌شده

```bash
python test.py \
    --input path/to/noisy.png \
    --checkpoint ./results/model.pth \
    --output ./results/inference
```

**نتیجه**: هر دو سمپلر به صورت جداگانه مؤثر هستند، اما **ترکیب آن‌ها** عملکرد را به طور قابل توجهی بهبود می‌بخشد.

### تاثیر Spectral Weighted Loss

| نوع Loss | α, β | σ=10 | σ=25 | σ=50 |

**نتیجه**: 
- Lossهای فرکانسی از نسخه مکانی بهتر عمل می‌کنند.
- وقتی **β > α** (وزن بیشتر برای HF)، عملکرد بهتر است.
- این نشان می‌دهد که تمرکز بیشتر روی فرکانس‌های بالا به حفظ جزئیات کمک می‌کند.

## نکات فنی

### ۱. چرا ابعاد تصویر باید زوج باشد؟
سمپلر Sd تصویر را به کاشی‌های ۲×۲ تقسیم می‌کند. اگر ابعاد فرد باشد، آخرین سطر/ستون ناقص می‌ماند. راه‌حل: قبل از پردازش، تصویر را crop کنید (`--crop_size 256`).

### ۲. چرا از کانال Y برای Sr استفاده می‌شود؟
- کانال Y (luminance) نسبت به رنگ، پایدارتر است.
- محاسبه شباهت روی Y به جای RGB، هزینه را به ۱/۳ کاهش می‌دهد.
- تغییرات رنگی (chromatic noise) کمتر روی شباهت پچ تاثیر می‌گذارند.

### ۳. چرا Pixel Bank یک‌بار ساخته می‌شود؟
ساخت Pixel Bank هزینه‌بر است (جستجوی سراسری). چون تصویر نویزی در طول آموزش ثابت است، بانک یک‌بار در ابتدا ساخته شده و در ایتریشن‌های بعدی استفاده می‌شود.

### ۴. تفاوت نویز گاوسی و پواسون
| ویژگی | گاوسی | پواسون |
|-------|-------|--------|
| توزیع | نرمال | پواسون |
| وابستگی به شدت | مستقل | وابسته به √(signal) |
| شبیه‌سازی | `noise = N(0, σ²)` | `noise = Poisson(λ·I)/λ` |
| کاربرد | نویز الکترونیکی | نویز فوتونی |

### ۵. نحوه محاسبه PSNR
```
PSNR = 20 × log10(MAX_I / √MSE)
```
که MAX_I برای تصاویر نرمال‌شده [۰,۱] برابر ۱ است.
